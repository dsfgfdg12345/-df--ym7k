扫码点餐与拼桌点餐技术实现——从桌码绑定到订单流转
扫码点单核心是桌码与桌号绑定：每个桌码对应一个桌号或包间，下单后订单自动归属该桌。系统通过带桌台标识的小程序码实现精准识别，门店下载小程序码/桌码张贴，顾客扫码即可自助点餐在线支付。

拼桌点餐和共同点餐只能任选一个。拼桌模式下生人共用一桌各自独立点餐下单，每人生成一笔订单，不支持部分商品打包外带，支付模式只支持先支付后下单。共同点餐适用于熟人同桌，扫描桌面二维码自助选台，同桌顾客可互相看到点餐内容，一桌生成一笔订单，支持先支付后下单和先下单后支付。

支付模式灵活支持先支付后下单和先下单后支付。先支付后下单顾客先支付再提交订单，可结合桌台手动清台；先下单后支付顾客点餐后商家开始备菜，吃完后付钱，未支付可加菜，也可关闭在线支付仅支持前台POS支付。

接单方式支持自动和手动。自动接单顾客下单或加菜后系统自动接单，先支付和后支付都支持；手动接单需人工确认，只支持后付。系统支持连接三方小票打印机，接单后自动打印。开启“选择上餐方式”后用户可选“立即制作上菜”或“等待通知再制作”，后者厨房出等叫单，适用于大型正餐客户，目前仅微信小程序支持。桌码链路、拼桌/共餐灵活选择和支付模式多样化配置构成堂食完整解决方案。
